# 郑嘉涛个人主页（韩山师范学院）

这是一个为 **郑嘉涛（逐梦.）** 定制的纯静态个人主页项目，采用原生 HTML5 + CSS3 + JavaScript 编写，无需任何构建工具或后端依赖，解压后直接用浏览器打开 `index.html` 即可浏览。

## 目录结构

```text
├── css/
│   └── style.css          # 页面样式、响应式布局与深浅色主题
├── images/
│   ├── avatar.jpg         # 个人头像（截取自微信主页）
│   ├── me.jpg             # 个人海边照片
│   ├── wechat.jpg         # 微信个人主页截图
│   ├── campus-gate.jpg    # 韩山师范学院 · 校门风光
│   ├── campus-library.jpg # 韩山师范学院 · 图书馆与广场
│   └── campus-lake.jpg    # 韩山师范学院 · 湖畔与林荫
├── js/
│   └── main.js            # 主题切换、一键复制、灯箱预览与滚动动画
├── index.html             # 网站主入口页面
└── README.md              # 项目说明文档
```

## 功能特性

- **响应式设计**：自动适配电脑端、平板与手机屏幕。
- **深浅色模式切换**：支持一键切换日间 / 夜间主题，并自动记住偏好设置。
- **图片灯箱预览**：点击个人照、微信主页或母校风光图均可放大查看，支持键盘左右键切换与 `Esc` 退出。
- **一键复制联系方式**：支持快速复制微信号（`z18924755922`）与视频号（`逐梦.1518`）。

## 替换母校图片说明

如果你想替换成你实拍的或对话中生成的韩山师范学院校园图片，只需将图片重命名为以下文件名并覆盖放入 `images/` 目录即可：

- `images/campus-gate.jpg`（校门）
- `images/campus-library.jpg`（图书馆）
- `images/campus-lake.jpg`（校园湖畔）

## 本地运行

1. 解压压缩包到任意文件夹。
2. 双击打开 `index.html`（推荐使用 Chrome / Edge 浏览器），或在 VS Code 中使用 **Live Server** 插件预览。
